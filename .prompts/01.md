Hi. I am giving you what supposed to be Python application using FastAPI.
In this project, please make no to little chaanges to provided frontend.
This application should browse some directory for json files an returns its content. One such of json file could look like this:
```json
{
    "name": {
        "_": "MySuperDuperApp",
        "en": "MySuperDuperApp",
        "cs": "Moje super duper apka"
    },
    "description":{
        "_": "Super usefull, ultra beautifull, easy to use app.",
        "cs": "Super užitečná, mimořádně krásná aplikace jednoduchá na použití."
    }
    "icon": "./path/to/icon.png",
    "accentColor": "#500106",
    "target": "/mysuperduperapp"
}
```
All settings of the applicationm should be stored in `.ini` file. This could look like this:
```ini
[server]
listen=0.0.0.0
port=8080

[hub]
root=path/to/directory
nested=true
```
Values of those means following:
 - `[server]` - server settings
   - `listen` - address, from which requests will be accepted
   - `port` - port, on which program will run
 - `[hub]` - application settings
   - `root` - path to directory, where application will look for `.json` files (application should support both absolute and relative path)
   - `nested` - flag, whether application will browse through nested directories too

Path to this `.ini` filer should be accepted either as application aargument or by default path (`config.ini` within the same directory, in which appliccation runs).
